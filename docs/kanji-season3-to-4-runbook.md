Season 3 の本番アーカイブ、バッジ付与、Season 4 の初期化は完了。`leaderboards/kanjiSeason3.resetCompletedAt` を記録済みのため、同じ保存・初期化処理を再実行しない。

- [PR #7](https://github.com/kazuki2kr-cyber/math-app/pull/7) を main に反映し、Vercel 本番と `createKanjiBattleRoom` Cloud Function を更新した。
- 更新直前に本番の漢字データをバックアップ。43 名の Season 3 参加者から通常・対戦の上位各 10 名を保存し、Lv.300 以上の 13 名に Season 3 バッジを付与した。
- 197 名全員の漢字レベルを 1、漢字 XP・対戦 XP・勝利数を 0 にし、現行の通常・対戦ランキングを空にした。保存後の検証で未初期化ユーザーと未付与バッジはともに 0 件。
- Season 1・2 のアーカイブと既存バッジ数は更新前後で一致した。対戦の試合履歴は削除していない。
- 漢字の単元・問題は現在 0 件。漢字メンテナンスは有効、数学は通常稼働のまま。問題登録後に `docs/kanji-all-random-pool.md` に従って対戦用プールを再作成し、漢字モードの再開を確認する。

以下は次回の切替に流用するための手順記録。今回の Season 3 処理には再使用しない。

## 確定した仕様

- Season 3 の認証条件は漢字 Lv.300 以上。認証画像は `public/images/kanji-season3-badge.png`。
- 通常演習の獲得XP上位10名と、対戦XP上位10名を `leaderboards/kanjiSeason3` に保存する。
- 保存した順位は漢字トップと対戦トップで、過去シーズンを選ぶ形で表示する。
- Season 4 の開始値は全員が漢字 Lv.1・0 XP。漢字の単元成績、スコア、対戦XP、勝利数と現行ランキングも初期化する。
- Season 1～3 のバッジと記録、数学データ、漢字利用認証、対戦の試合履歴は保持する。

## 実施順序

1. 切替日時を決め、漢字演習と新規対戦を停止する。進行中の対戦を終了させる。
2. 本番の `users`、`leaderboards/kanji`、`leaderboards/kanjiBattle`、過去シーズンのアーカイブをバックアップし、保存済み Season 1・2 を照合する。
3. 品質チェックに通った本変更を本番へ反映する。更新後の管理画面が「Season 3を保存」と表示することを確認する。
4. 管理画面の「Season 3を保存」を一度実行する。通常・対戦の上位10名、認証対象人数、実際のバッジ付与を確認する。既存の `kanjiSeason3` がある場合は上書きしない。
5. 「保存済み記録を確認して一括リセット」を実行する。途中失敗時は同じ保存済み記録を用いて再実行する。`resetCompletedAt` が記録されたら再実行しない。
6. 全ユーザーの漢字XP・レベル・対戦成績と現行ランキング、過去順位、認証バッジ、試合履歴保持を確認する。新しい演習と対戦で Lv.1・0 XP から加算されることを確認して利用を再開する。

Season 3 の保存とバッジ付与は別操作。一括リセットはユーザー数が497人以下なら現行ランキングと完了記録を含めて原子的に更新する。上限を超える場合は初期化を中止する。切替中に演習・対戦を許可すると、新しい成績がリセット対象になるため、利用停止を維持する。
